# 单词助手 (Word Assistant)

[English](./README_EN.md)

一个简洁高效的 Android 单词学习背诵应用，采用单页集成架构 (SPA)，提供全局搜索、单词标记、随机复习及例句语境学习等全方位功能。

## 功能特性

- **JSON 单词表导入**：支持从外部导入标准 JSON 格式单词数据，支持包含例句与翻译的复杂结构。
- **按列表分组**：自动识别 JSON 中的 `list`字段进行分组管理，支持无限扩展。
- **三合一集成界面**：
    - **学习模式**：列表化展示，支持点击单词展开释义，标记生词并持久化保存。
    - **复习模式**：针对当前列表进行随机四选一测试，支持即时反馈、智能干扰项生成及答题进度记忆。
    - **例句模式**：自动展示单词原比例句，支持点击切换中英文对照，在真实语境中强化记忆。
- **全方位搜索**：支持在学习和例句模式下按单词、中文释义或例句内容（含翻译）进行全库模糊匹配搜索。
- **统一导航体验**：采用顶部卡片式导航设计，分页、跳转及模式切换功能均置于页面上方，操作触手可及。
- **完美适配深色模式**：支持系统级深色模式切换，保护视力，提供舒适的背诵体验。

## 技术栈

- **Android Kotlin**：原生 Android 开发框架。
- **WebView**：高性能 Web 容器加载核心逻辑界面。
- **HTML/CSS/JavaScript**：响应式前端界面与交互逻辑。
- **JSON**：标准数据交互与存储格式。

## 快速开始

### 环境要求

- Android Studio Flamingo 或更高版本
- JDK 17+

### 导入单词表格式

```json
[
    {
      "word":"apple",
      "meaning":"n. 苹果",
      "examples":{
        "example1":{
          "sentence":"I have an apple.",
          "emeaning":"我拥有一个苹果。"
        }
      },
      "list":"list1"
    }
]
```

## 使用说明

- **模式切换**：通过页面顶部的导航栏，点击“去学习”、“去复习”或“去例句”按钮即可跳转。
- **交互细节**：
    - **学习/例句模式**：点击单词行展示释义，在例句模式下点击英文例句展示/隐藏中文翻译。
    - **复习模式**：点击选项即可答题，系统会在答对后 0.5 秒自动跳转至下一题。
- **全局搜索**：搜索框位于顶部导航下方，输入关键词后自动检索当前所有列表内容。
- **清除标记**：点击“清除本页标记”可重置当前页面的标记状态。
